# Монитор сотового сигнала

Это проект графического приложения для мониторинга и визуализации уровней сотового сигнала и его характеристик (RSSI, RSRP, RSRQ, высота).

## Возможности
- **Отслеживание точек данных**: сбор и хранение данных в реальном времени или их перенос из файла `locations.json` с помощью `migrate.py`.
- **История сигналов**: построение линейных графиков среднего и максимального уровня сигнала.
- **Генерация тепловой карты**: создание тепловых карт.
  - Выбор критерия: RSRP, RSRQ, RSSI, высота.

## Сборка и запуск
1. `mkdir build && cd build`
2. `cmake ..`
3. `make`
4. `./bin/cell_signal_monitor`


**Особенности:**
- **Строгие ограничения радиуса**: интерполяция учитывает только экспериментальные точки данных в пределах выбранного радиуса 10–200 м.
- **Цветовая градация**: используются стандартные цветовые карты. Например, RSRP градируется от **тёмно-синего** (плохой/слабый сигнал, от -100 до -110 дБм) до **красного** (отличный сигнал > -80 дБм). Сигналы ниже -110 дБм («Нет сигнала») остаются прозрачными.
- **Сохранение изображения**: приложение вычисляет одно большое комбинированное изображение для всех точек и сохраняет полученную текстуру в каталог `build/heatmap.png`.
